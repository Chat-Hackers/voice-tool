# Voice Forwarding Tool

Voice forwarding tool for Chat Hackers groups.

This app forwards voice messages from a group chat to an external url.

## Getting started

1. Clone the repo
1. Run the command `npm install`
1. Run the command `npm run dev`
1. Copy the `voice.json` file and paste into the `registrations` folder of [the tool hub](https://github.com/chat-hackers/tool-hub)
1. Restart the tool-hub and then paste the gear emoji to see the tools
